สำคัญ: การเก็บข้อมูลและการเปลี่ยนเครื่อง

เว็บสร้างตัวตนแบบไม่ระบุชื่อเบื้องหลัง และเก็บสิทธิ์เข้าถึงไว้ในเบราว์เซอร์นี้ ข้อมูลจริงอยู่บน Supabase แต่หากล้างข้อมูลเว็บไซต์หรือเปลี่ยนเบราว์เซอร์ จะไม่กลับเข้าชุดข้อมูลเดิมอัตโนมัติ

ควรสำรอง JSON เป็นระยะ และนำเข้าไฟล์นั้นเมื่อต้องย้ายเครื่อง การนำเข้าเป็นการสร้างสำเนา ไม่ได้ทำให้สองเครื่องซิงก์กัน

1. ตู้และแหล่งน้ำ

2. บันทึกค่าน้ำ

ไม่ได้ตรวจให้เว้นว่าง ค่า 0 หมายถึงบันทึกผลตรวจเป็นศูนย์

3. บันทึกการดูแลตู้

4. ค่าล่าสุดของสถานที่นี้

5. กราฟและช่วงประวัติ

6. ประวัติค่าน้ำ

ค่าที่แสดงเป็นหน่วยเดียวกับแบบฟอร์มด้านบน
วันเวลาpH°CTDSEC GHKHNH₃/NH₄⁺ NO₂⁻NO₃⁻หมายเหตุจัดการ

7. ประวัติกิจกรรม

วันเวลากิจกรรมปริมาณ แหล่งน้ำกำจัดสารฆ่าเชื้อ หมายเหตุจัดการ

8. คำนวณ TDS หลังเปลี่ยนน้ำโดยประมาณ

สมมติว่าถ่ายน้ำออกแล้วเติมกลับเท่าปริมาตรเดิมและผสมทั่วถึง เป็นเพียงค่าประมาณ ไม่ใช่ผลตรวจ GH หรือคำยืนยันว่าปลอดภัยสำหรับสัตว์น้ำ

9. สำรองและนำเข้าข้อมูล

JSON สำรองทุกสถานที่ ส่วน CSV ส่งออกเฉพาะสถานที่และช่วงวันที่ที่เลือก การนำเข้าเป็นการเพิ่มข้อมูล หากนำเข้าไฟล์เดิมซ้ำจะได้ข้อมูลซ้ำ

10. ใช้ข้อมูลร่วมกันหลายเครื่อง

เครื่องที่มีข้อมูลอยู่ให้กด "แสดงรหัสเข้าถึง" แล้วนำรหัสไปกรอกในเครื่องอื่น ทุกเครื่องจะเห็นและแก้ข้อมูลชุดเดียวกัน ผู้ที่มีรหัสเข้าถึงข้อมูลทั้งหมดได้ จึงควรเก็บเป็นความลับ
